# Healthy leaf 🌿

## Project problem
A business named "Healthy Leaf" has a physical store but no online website which lead to loss of customers.

## Solution: 
Making a website to help them expand their range of customers.

1- Customers can book diet trainers. 

2- Customers can order customized meals to fit their need of carbs, protain, fibers and healthy fats.
